## Historical Role And Result

The commit adds generic source-bound generated mechanical-part CAD: typed
generated shaft/hub/frame authority, deterministic CAD lowering, candidate and
canonical generated-part realization, semantic placement derivations,
promotion/canonical reconstruction, and bounded M10 integration. It consumes
M13-1 supplied-component interface authority.

New CAD primitives are cylindrical stock and axial bore, with base/coordinate
exclusivity and containment validation. The FreeCAD backend emits
`Part.makeCylinder` and subtractive bores, and verifies shape validity, single
solid, bounding box, and analytic volume in a fresh subprocess. Generated
geometry identity is the sorted union of input and binding hashes, so distinct
binding graphs remain distinct. Promotion uses mapping schema
`candidate-canonical-mapping@2` and canonical schema
`canonical-component-specification@3`/`canonical-physical-mechanism@2`, with
`@1` payloads omitting generated derivations so legacy hashes stay stable.
