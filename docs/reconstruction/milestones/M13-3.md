## Historical Role And Result

physical-pair-policy authority plus deterministic lowering to the existing M10
v2 surface. A single pure core (`_compile_physical_to_m10_core`) feeds candidate
and canonical adapters. It validates one body owner and one CAD mapping per
physical instance, a single root with one incoming joint per non-root and an
acyclic tree, semantic placements/offsets, and source-local axis lowering into
the parent-reference frame.

Candidate and canonical share a stable `physical-to-m10-v2-model@1` model ID for
identical topology. Candidate/canonical equivalence compares after explicit
physical/CAD ID projection under `rigid-transform-agreement@1.0` and does not
require raw hash equality. Only cross-body `CHECK_CLEARANCE` pairs become
`ExactConstituentPair` scope; same-body pairs must be `SAME_RIGID_GROUP_EXCLUDED`.
Fresh canonical verification rebuilds a fresh canonical bridge, model, scope,
and request and executes through the trusted tolerance adapter without touching
generic M10 production modules.
