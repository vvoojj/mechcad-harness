## Intended Scope

M0 established a Python 3.11+ `src` package foundation with Pydantic v2 domain
models, readable centralized identifiers, canonical `DesignState`, separate
proposal/result/validation/issue/evidence records, revision/state-hash binding,
placeholder YAML configuration, tests, and repository/agent boundary
documentation.

It deliberately excluded agents, real OpenCode execution, CAD, FreeCAD, FEA,
scheduling, dependency execution, LLM workflows, databases, and external
services.

## Actual Implementation

The root tree added `pyproject.toml`, `.gitignore`, `src/mechcad_harness/`,
workspace and integration-test placeholders, configuration placeholders, and
the M0 documentation.

`IdPrefix`, `generate_id(...)`, and `id_prefix(...)` provided readable
UUID-backed IDs. The initial typed model surface included `DesignState`, the
engineering entities, task/result, proposal/change-set, issue, validation,
evidence, run-manifest, and `StateBinding` records.

`DesignState` held canonical engineering state and excluded evidence and
results. External records bound to state through revision and state hash.
Models rejected extra fields, required non-empty identifying strings, used
positive revisions, provided UTC-aware timestamps, and used enums for status
fields.

Six unit tests existed: two identifier tests and four model tests. They covered
identifier behavior, basic construction, invalid names/revisions, state binding,
and the `DesignState` separation boundary.
