# M8C-2 — Specialized CAD Artifact → Typed Imported Component → Generic Assembly Bridge

**Date:** 2026-08-21  
**Status:** Design  
**Milestone:** M8C-2

## 1. Initial Gap

Before M8C-2, `CadAssemblyProgram` could only reference `CadPartProgram` components generated by the generic FreeCAD CAD compiler. The specialized gear-CAD path (py_gearworks/build123d) produces STEP artifacts stored in `ArtifactStore`, but these artifacts cannot enter the generic assembly pipeline. There is no typed bridge to import external STEP artifacts as assembly components.

## 2. Design

### 2.1 Imported Component Model

Introduce `ImportedCadComponent` — a typed generic model representing a trusted external CAD artifact as an assembly component.

```python
class ImportedCadComponent(Model):
    component_id: str = Field(min_length=1)
    artifact_id: str = Field(min_length=1)
    artifact_hash: str = Field(min_length=1)  # sha256 from ArtifactStore
    format: Literal["step"] = "step"
    source_revision: int = Field(gt=0)
    source_state_hash: str = Field(min_length=1)
```

**Key properties:**
- Domain-neutral: no gear/Yagi/antenna semantics
- Trust-bound: references `ArtifactStore` record by ID, not arbitrary file paths
- Deterministic: component identity includes artifact content hash

### 2.2 Artifact Trust Model

Trust chain:
1. Caller provides `artifact_id` and `artifact_hash`
2. Bridge resolves artifact via `ArtifactStore.existing(artifact_id)`
3. Verifies artifact exists, type is STEP, and `sha256` matches `artifact_hash`
4. Only then creates `ImportedCadComponent`

Fail-closed behavior:
- Missing artifact → rejection
- Hash mismatch → rejection
- Wrong format → rejection
- Arbitrary file path bypass → rejection

### 2.3 Assembly Integration

Extend `CadAssemblyProgram` to accept either `CadPartProgram` or `ImportedCadComponent`:

```python
class CadAssemblyProgram(Model):
    assembly_id: str = Field(min_length=1)
    parts: tuple[CadPartProgram, ...] = Field(default_factory=tuple)
    imported_components: tuple[ImportedCadComponent, ...] = Field(default_factory=tuple)
    instances: tuple[CadComponentInstance, ...] = Field(min_length=1)
    
    @model_validator(mode="after")
    def validate_registry(self) -> "CadAssemblyProgram":
        part_ids = [part.part_id for part in self.parts]
        imported_ids = [comp.component_id for comp in self.imported_components]
        all_component_ids = part_ids + imported_ids
        # ... validation logic
```

**Backward compatibility:** Existing code using `parts` field continues to work. The `parts` field becomes optional but at least one of `parts` or `imported_components` must be non-empty.

### 2.4 Deterministic Identity

Assembly hash includes:
- `assembly_id`
- Generated part hashes (from `CadPartProgram`)
- Imported component identity (component_id, artifact_id, artifact_hash)
- Component type discrimination (generated vs imported)
- Instance ordering and transforms

### 2.5 FreeCAD Backend Extension

Extend `FreeCADAssemblyBackend.generate_assembly()` to:
1. For each `CadPartProgram` component: existing path (generate FCStd, verify, import)
2. For each `ImportedCadComponent`: 
   - Resolve artifact via `ArtifactStore`
   - Import STEP file into FreeCAD
   - Verify shape/solid validity
   - Place instance with transform

### 2.6 Provenance

Assembly result provenance includes:
- Generated component provenance (existing)
- Imported component artifact identity and hash
- Backend version for STEP import
- Assembly program hash

## 3. Trusted Artifact Path

```
Specialized producer (py_gearworks/build123d)
  → ArtifactStore.publish(artifact_id, STEP, content, ...)
  → EngineeringArtifact record with sha256

Assembly consumer:
  → ArtifactStore.existing(artifact_id)
  → Verify sha256 matches expected hash
  → Import STEP into FreeCAD
  → Verify shape validity
  → Place in assembly
```

## 4. Generic Imported Component

**Type:** `ImportedCadComponent`  
**Identity fields:** component_id, artifact_id, artifact_hash  
**Supported formats:** STEP (M8C-2 scope)  
**Provenance fields:** source_revision, source_state_hash  
**Domain-neutral:** yes — no gear/motor/antenna semantics

## 5. CadAssemblyProgram Integration

```python
# Generated component (existing)
part = CadPartProgram(part_id="mounting-plate", operations=(...))

# Imported component (new)
imported = ImportedCadComponent(
    component_id="gear-1",
    artifact_id="ART-abc123",
    artifact_hash="sha256:def456...",
    format="step",
    source_revision=5,
    source_state_hash="sha256:...",
)

# Assembly with both
assembly = CadAssemblyProgram(
    assembly_id="test-assembly",
    parts=(part,),
    imported_components=(imported,),
    instances=(
        CadComponentInstance(instance_id="plate-inst", part_id="mounting-plate"),
        CadComponentInstance(instance_id="gear-inst", part_id="gear-1"),
    ),
)
```

## 6. Deterministic Identity

**Imported component identity:**
- `component_id` (caller-specified, must be unique in assembly)
- `artifact_id` (from ArtifactStore)
- `artifact_hash` (content hash, change changes identity)
- `format` (STEP)
- `source_revision` and `source_state_hash` (provenance binding)

**Assembly program identity includes:**
- All imported component identities
- Component type discrimination in hash payload
- Deterministic ordering (canonical by component_id)

## 7. Production Entry Path

```
ProductionApplication.compile_design_spec()  # existing
  → CadCompilationResult with CadPartProgram

# New: resolve imported artifact and build assembly
ProductionApplication.build_assembly_with_imported_components(
    source_revision, source_state_hash,
    generated_program, imported_components, instances, workspace, run_id
)
  → CadAssemblyGenerationService.generate_assembly_with_imported()
  → FreeCADAssemblyBackend with STEP import
```

## 8. FreeCAD Backend Path

```
CadAssemblyProgram
  → for each component:
      if CadPartProgram: existing generate path
      if ImportedCadComponent:
        → ArtifactStore.existing(artifact_id)
        → verify sha256 matches
        → FreeCAD Part.insert(step_path)
        → verify shape valid, non-null, solid
  → for each instance:
      → place with CadRigidTransform
  → export FCStd/STEP
  → fresh reload verification
  → persist to ArtifactStore
```

## 9. Provenance

```
Specialized producer → ArtifactStore record (artifact_id, sha256)
  → ImportedCadComponent (references artifact_id, artifact_hash)
    → CadAssemblyProgram (includes component in hash)
      → FreeCADAssemblyGenerationResult (assembly provenance includes artifact identity)
```

## 10. Gear Fixture

A gear STEP artifact may be used as proof fixture. The generic bridge:
- Does NOT know about gear geometry
- Does NOT import py_gearworks or build123d
- Only trusts ArtifactStore records with valid SHA-256

The fixture demonstrates the bridge works; the bridge itself is domain-neutral.

## 11. Failure Behavior

| Condition | Behavior |
|---|---|
| Artifact record not found | `ImportedArtifactNotFoundError` |
| Hash mismatch | `ImportedArtifactIntegrityError` |
| Unsupported format | `UnsupportedImportedFormatError` |
| STEP import failure | `FreeCADExecutionError` (existing) |
| Shape invalid/null | `FreeCADArtifactVerificationError` (existing) |
| Invalid component identity | Pydantic validation error (existing) |
